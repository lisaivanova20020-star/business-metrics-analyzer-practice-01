# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения».

## Бизнес-задача

Расчёт и визуализация ключевых показателей эффективности (KPI) предприятия.

## Планируемые метрики

В рамках проекта предусмотрен расчёт следующих показателей эффективности предприятия:

- **Выручка** — общая сумма денежных средств, полученных от деятельности предприятия.
- **Затраты** — расходы предприятия за определённый период.
- **Прибыль** — разница между выручкой и затратами.
- **Рентабельность** — отношение прибыли к выручке, выраженное в процентах.
- **Средняя выручка** — среднее значение выручки за рассматриваемые периоды.
- **Общая рентабельность** — показатель эффективности деятельности предприятия за весь рассматриваемый период.

Полученные показатели позволяют оценивать финансовые результаты предприятия и анализировать эффективность его деятельности.
